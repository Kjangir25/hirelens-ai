# 🎯 HireLens AI

**HireLens AI** is an AI-powered recruitment and candidate screening platform designed to streamline and automate the hiring process. It helps recruiters evaluate resumes, analyze candidates, and make faster, data-driven hiring decisions.

🌐 **Live Demo:** [hirelens-ai-plum.vercel.app](https://hirelens-ai-plum.vercel.app)

---

## 🚀 Features

- 📄 **Smart Resume Parsing:** Automatically extracts key skills, experience, and candidate details.
- 🤖 **AI Candidate Matching:** Ranks candidates based on job description alignment and requirements.
- ⚡ **Streamlined Workflow:** Reduces screening time and optimizes recruiter productivity.
- 📊 **Insightful Dashboards:** Provides clear evaluations and scoring for quick decision-making.
